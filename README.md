# Cadensa

**Encuentra el ritmo de tu voz. (Find the rhythm of your voice)**

Una plataforma diaria que entrena tu ritmo al hablar para superar bloqueos y comunicarte con total seguridad.

## Concepto Clínico
Se basa en el "ritmo" y el "habla rítmica silábica" (syllable-timed speech), una técnica clínica comprobada para reducir la tartamudez enseñando al usuario a hablar con un ritmo constante.

Cadensa es un nombre de marca inspirado en la palabra "cadencia". La cadencia es el ritmo, la velocidad y la regularidad con la que se producen sonidos, palabras o movimientos.

## Stack Tecnológico (PoC)
- **Front-end**: Next.js (App Router, Client Components, Tailwind CSS, TypeScript).
- **Back-end**: Supabase (PostgreSQL, RLS).
- **Despliegue**: Cloudflare Pages.
- **CI/CD**: GitHub Actions.
